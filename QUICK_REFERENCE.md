---

## 📝 **Admin Workflow**

```
1. Login with: admin / admin123
2. Click "Manage Students"
3. Enter: Name, Username, Password
4. Click "Create Student"
5. Give credentials to student
```

---

## 🎯 **Student Workflow**

```
1. Click "User Login" tab
2. Enter credentials
3. Select topic from dropdown
4. Click "Start Quiz"
5. Answer all questions
6. Submit to see score
7. Click "Next" for another quiz
```
